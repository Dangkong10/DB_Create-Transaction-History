2. 문제의 상태 — 세션 만료

문제 — 온라인인데도 영원히 이 상태. 원인도, 사용자가 할 일도 안 보임.

수정 후 로그인 필요 — 3건 미전송 TO-BE

해결 — 원인이 드러나고, 탭하면 재시도 / 로그인 화면으로. 데이터는 기기에 그대로 남아 있음.

3. "로그인 만료" 팝업

AS-IS

로그인 만료

로그인이 만료되어 동기화되지 않은 3건의 내용이 있습니다. 이 내용은 저장되지 않습니다. 계속하시겠습니까?

이 버튼이 3건을 영구 삭제 (clearPendingSync + wipeAllLocalData)

TO-BE

로그인 만료

로그인이 만료되어 아직 전송되지 않은 3건이 있습니다. 이 내용은 기기에 안전하게 남아 있으며, 다시 로그인하면 이어서 전송됩니다.

어느 버튼을 눌러도 데이터는 지워지지 않음
